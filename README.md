# RS-VPN

تطبيق Android مكتوب بلغة Kotlin يتصل بخادم SSH ويوفر وكيل SOCKS5 محليًا على `127.0.0.1:1080` عبر SSH Dynamic Forwarding.

## الميزات

- تحميل قائمة الخوادم من رابط HTTPS.
- دعم الصيغ: JSON، YAML، روابط `ssh://`، Base64، وسطور نصية مفصولة بفواصل.
- قياس زمن الاستجابة لكل خادم واختيار الأسرع تلقائيًا.
- اختيار خادم يدويًا من القائمة.
